Privacy Policy

Last updated: July 2, 2026

At speekto.me, we value your privacy. This policy outlines how we handle audio recordings and transcribed text when you use our desktop application and cloud API services.

1. Data Collection & Processing

To perform transcription, our application records audio locally from your microphone ONLY when you trigger the hotkey. This audio is downmixed to 16kHz mono and immediately compressed into a secure Ogg/Opus container.

This compressed audio is sent via HTTPS POST requests directly to our backend server. We do **NOT** store raw audio recordings on our servers. Once the transcription request is completed by Groq Whisper, the audio data is discarded immediately from temporary memory.

2. Transcription and Enhancement API

Audio transcription is processed via Groq's Whisper v3 Turbo API. If text formatting or enhancement is enabled, the resulting transcript is sent to DeepSeek's AI models. Both APIs process the data in real-time under strict confidentiality agreements. None of your data is used to train machine learning models.

3. Usage Logging

To enforce rate limits and subscription quotas (like the 50-hour monthly limit), we log metadata about requests in a secure database. This includes: user ID, timestamp, transcribed audio duration (in seconds), Whisper and LLM latency statistics, and request status.

4. Changes to This Policy

We may update this policy occasionally. Any changes will be posted on this page.

5. Contact Us

For questions regarding privacy or data handling, contact us at: contact@synaptican.com.
