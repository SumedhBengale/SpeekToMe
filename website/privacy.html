Privacy Policy

Last updated: July 2, 2026

At SpeekTo.Me, we value your privacy. This policy outlines how we handle audio recordings and transcribed text when you use our desktop application and cloud API services.

1. Data Collection & Processing

To perform transcription, our application records audio locally from your microphone only when you actively trigger the hotkey. This audio is immediately compressed using secure local processing.

This compressed audio is sent via secure encrypted requests directly to our backend server. We do not store raw audio recordings on our servers. Once the transcription request is completed, the audio data is discarded immediately from temporary memory.

2. Transcription and Enhancement

Audio transcription is processed via secure, state-of-the-art translation systems. If text formatting or enhancement is enabled, the resulting transcript is processed using modern language models to clean grammar and punctuation. Both services process the data in real-time under strict confidentiality agreements. None of your data is ever used to train machine learning models.

3. Usage Logging

To enforce rate limits and subscription quotas, we log metadata about requests in a secure database. This includes: user ID, timestamp, transcribed audio duration (in seconds), transcription and AI formatting latency statistics, and request status.

4. Changes to This Policy

We may update this policy occasionally. Any changes will be posted on this page.

5. Contact Us

For questions regarding privacy or data handling, contact us at: contact@synaptican.com.
